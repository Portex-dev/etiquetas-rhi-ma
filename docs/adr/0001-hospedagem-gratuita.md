# Hospedar a interface no GitHub Pages e os serviços no Supabase Free

Como a primeira versão precisa estar disponível pela internet sem orçamento, a interface será publicada no GitHub Pages a partir de um repositório público, enquanto banco de dados, autenticação administrativa e armazenamento de fotos ficarão no Supabase Free. Essa separação aceita os limites de capacidade dos planos gratuitos em troca de não manter um servidor próprio; nenhum segredo, registro ou foto será armazenado no repositório público.

## Consequences

- O sistema não imporá um limite funcional de registros, mas avisará quando o armazenamento estiver próximo da cota disponível.
- Imagens de até 10 MB poderão ser enviadas e serão reduzidas para aproximadamente 1600 pixels e, preferencialmente, menos de 1 MB antes do armazenamento.
- Os QR Codes só deverão ser impressos depois que o endereço público definitivo estiver confirmado.
